What is Python?

Python is a high-level, general-purpose programming language known for its clean, readable syntax that looks very similar to everyday English.

Why is it great for beginners?

  • Easy to Read & Write: Python avoids complex punctuation (like curly braces and semicolons) in favor of clean indentation.
  • Versatile: You can use it for web development, data science, artificial intelligence, and automating boring tasks.
  • Massive Community: Millions of developers use Python, meaning tutorials, free tools, and answers to your questions are everywhere.

Step 1: Setting Up Your Environment

Before writing code, you need two things on your computer:

  • The Python Interpreter: Download the latest version from python.org. (Tip: Windows users should check the box that says "Add Python to PATH" during installation).
  • A Code Editor: Download a beginner-friendly editor like VS Code or PyCharm Community Edition.

Step 2: Writing Your First Python Code

Create a new file in your editor named hello.py and try these three foundational concepts:

1. Printing Output

The print() function displays text on your screen.

# Lines starting with # are comments for humans; Python ignores them
print("Hello, World!")
Output: Hello, World!

2. Variables & Data

Variables act like labeled boxes that store information for later use.

name = "Alex"
age = 25

print("My name is", name)
print("Next year I will be", age + 1)
Output:
My name is Alex
Next year I will be 26

3. Making Decisions (If/Else)

Python uses indentation (spaces) to group code that runs only when a condition is true.

temperature = 75

if temperature > 70:
    print("It's a warm day!")
else:
    print("Bring a jacket.")
Output: It's a warm day!

Where to Go From Here?

Once you are comfortable with printing, variables, and if statements, explore these topics next:

  • Loops (for and while): Repeat tasks automatically without rewriting code.
  • Lists & Dictionaries: Store collections of items together.
  • Functions (def): Bundle your code into reusable mini-programs.
