1. What is Python & How Does It Work?

Python is a high-level, interpreted, general-purpose programming language created by Guido van Rossum and first released in 1991. Its design philosophy emphasizes code readability with its notable use of significant indentation.

Interpreted Language

Unlike C++ or Java, you don't need to compile Python code into machine language before running it. An interpreter reads and executes your code line-by-line, making testing and debugging fast.

Dynamically Typed

You don't have to declare what type of data a variable holds (like text or numbers) beforehand. Python figures it out automatically while the program runs.

"Batteries Included"

Python ships with a massive Standard Library containing pre-written tools for math, working with files, generating random numbers, dates, and web requests.

Where is Python Used?

Artificial Intelligence (PyTorch, TensorFlow), Data Science (Pandas), Web Backends (Django, FastAPI), Cybersecurity, and Task Automation.

2. Setting Up Your Local Environment

While you can practice right here on this page, real-world development happens on your computer. Follow these steps to set up a professional workflow:

  1. Install Python: Visit python.org and download the latest Python 3 installer. Important: On Windows, check the box labeled "Add python.exe to PATH" on the very first screen.
  2. Verify in Terminal: Open your Command Prompt (Windows) or Terminal (Mac/Linux) and type python --version (or python3 --version). You should see a version number like Python 3.12.x.
  3. Choose an IDE / Code Editor: Install Visual Studio Code (VS Code) and add the official Microsoft Python Extension. It gives you syntax highlighting, autocomplete, and a built-in terminal.
  4. Create & Run a File: Save a file as app.py, write print("Ready!") inside, and run python app.py in your terminal.
Golden Rule of Python Syntax: Python uses indentation (4 spaces) instead of curly braces {} to define blocks of code. Mixing tabs and spaces or indenting inconsistently will cause an IndentationError.

3. Variables, Data Types & Strings

A variable is a name attached to a piece of data stored in your computer's memory. In Python, variable names should use snake_case (all lowercase words separated by underscores).

Data Type Python Keyword Example Description
String str "Hello" Text enclosed in single or double quotes.
Integer int 42 Whole numbers (positive or negative).
Float float 19.99 Numbers with a decimal point.
Boolean bool True / False Logical truth values (must be capitalized).

Modern String Formatting (f-strings)

Put the letter f before your opening quote to inject variables directly inside curly braces {}:

username = "Maya"
score = 98.5
print(f"Player {username} scored {score}% on the test!")

4. Data Structures: Lists & Dictionaries

When you need to store multiple items together, Python provides built-in data structures.

Lists (Ordered Collections)

Lists use square brackets [] and are zero-indexed (the first item is at position 0).

languages = ["Python", "JavaScript", "Rust"]
print(languages[0])          # Outputs: Python
languages.append("Go")       # Adds "Go" to the end
print(len(languages))        # Outputs: 4

Dictionaries (Key-Value Pairs)

Dictionaries use curly braces {} to map unique keys to values—just like a real dictionary maps words to definitions.

developer = {
    "name": "Jordan",
    "role": "Backend Engineer",
    "experience_years": 3
}
print(developer["role"])     # Outputs: Backend Engineer
developer["city"] = "Austin" # Adds a new key-value pair

5. Conditionals & Loops

Control flow determines the order in which your code executes based on conditions or repetition.

If, Elif, and Else

Comparison operators include == (equal to), != (not equal), >, <, >=, and <=.

battery = 15

if battery > 50:
    print("Battery is healthy.")
elif battery > 20:
    print("Battery is getting low.")
else:
    print("Plug in your charger immediately!")

For Loops & While Loops

Use a for loop to iterate over a list or a range of numbers, and a while loop to repeat code as long as a condition remains True.

# Loop through a range of numbers (1 to 3)
for number in range(1, 4):
    print(f"Countdown: {number}")

# Loop through a list
tasks = ["Code", "Test", "Deploy"]
for task in tasks:
    print(f"Completed: {task}")

6. Writing Reusable Functions

A function is a reusable block of code that performs a specific task. You define it once with def and call it whenever you need it. Use return to send a result back from the function.

def calculate_tax(amount, tax_rate=0.08):
    """Calculates total price including tax."""
    total = amount + (amount * tax_rate)
    return round(total, 2)

# Calling the function with different inputs
print(calculate_tax(100))        # Uses default 8% tax -> 108.0
print(calculate_tax(100, 0.10))  # Overrides with 10% tax -> 110.0

7. Next Steps: Debugging, Libraries & Projects

How to Read Python Error Messages

Every developer hits errors daily. When Python crashes, read the Traceback from the bottom up—the very last line tells you what went wrong and which line number caused it:

  • SyntaxError: You missed a colon :, parenthesis ), or quote ".
  • NameError: You used a variable or function name that hasn't been defined yet (check for typos!).
  • TypeError: You tried to combine incompatible types (e.g., adding a string and an integer like "Age: " + 25).

Using External Packages with pip

Python's biggest superpower is PyPI (the Python Package Index), which hosts over 500,000 free libraries. You install them from your terminal using pip:

# Run this in your computer's terminal, not inside a .py file:
pip install requests
